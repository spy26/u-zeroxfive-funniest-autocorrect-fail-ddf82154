The funniest autocorrect fail, in one line:

> I got the mob! Starting Monday, 9 to 5, great benefits.

`main.ts` writes exactly that line (55 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` — deterministic, and it reads nothing from outside the repo.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output npx tsx main.ts
```
